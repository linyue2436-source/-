# 简历星球

基于 React + TypeScript + Vite + Tailwind CSS 的中文简历制作网站。

## 本地运行

建议使用 Node.js 22.12+ 或 Node.js 24。

```bash
npm ci
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 已实现

- 中文首页，包含产品介绍与制作流程。
- 基本信息、个人简介、工作经历、项目经历、教育背景、专业技能编辑。
- 工作、项目、教育条目增删，A4 实时预览，四种主题色。
- 桌面双栏布局，手机编辑 / 预览切换。
- 当前浏览器 localStorage 自动保存，JSON 备份下载与导入。
- 浏览器打印及另存为 PDF；打印时关闭浏览器的页眉和页脚。

## 说明

没有支付、登录、数据库或后端服务。简历内容保存在当前浏览器，不会上传到服务器；不同设备、浏览器之间不会自动同步。建议定期下载 JSON 备份。

主题色仅在当前页面会话中生效。A4 屏幕预览按比例显示，内容较长时会自然扩展；打印时由浏览器分页，并尽量保持同一条经历完整。
